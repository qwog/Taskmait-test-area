# ProspectPilot (Apollo/ZoomInfo-style Demo)

ProspectPilot is a lightweight sales intelligence demo inspired by Apollo.io and ZoomInfo.
It includes:

- Contact and company search with advanced filters
- Lead list saving and list management
- Contact enrichment simulation
- Email sequence enrollment and activity tracking
- Pipeline-style deal tracking
- Dashboard analytics

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open `http://localhost:5000`.

## Notes

This is a demo app with in-memory data and mock enrichment behavior.
