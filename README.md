# CareMait

CareMait is a responsive single-page web app inspired by the provided product-plan image. It presents:

- Executive summary
- Competitive landscape
- Product overview
- Monetization model
- Technical architecture
- Go-to-market strategy
- 30-day MVP sprint plan
- Success metrics

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
